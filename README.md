# موقع مؤسسة دلما الجزيرة للمقاولات

موقع مؤسسي متعدد الصفحات مبني بـ Next.js 15 وReact 19 وTypeScript وTailwind CSS 4. يُصدَّر كموقع ثابت (Static Export)، فيشتغل على أي استضافة ثابتة: GitHub Pages أو Cloudflare Pages أو غيرها.

## الصفحات
| المسار | الصفحة |
| --- | --- |
| `/` | الرئيسية |
| `/about/` | من نحن، ومعها قسم القيادة والإدارة |
| `/products/` | منتجاتنا وخدماتنا |
| `/products/wpc-doors/` | أبواب WPC |
| `/products/upvc/` | أبواب وشبابيك UPVC |
| `/products/aluminium-glass/` | الألمنيوم والزجاج والواجهات |
| `/works/` | نماذج من أعمالنا ومنتجاتنا (مع تصفية وعارض صور) |
| `/catalogue/` | كتالوج ألوان WPC من P01 إلى P19 |
| `/contact/` | تواصل معنا |
| `/quote/` | طلب عرض سعر |

## تعديل المحتوى
كل بيانات المؤسسة في ملف واحد هو **`src/content/site.ts`**:
- بيانات التواصل والأرقام والعنوان والحسابات.
- الخدمات والموديلات والمواصفات.
- صور الأعمال وأكواد الألوان.
- أعضاء القيادة والإدارة. لإضافة شخص، أضف عنصرًا في `leadership`. ولإضافة نبذة معتمدة، عبّئ الحقل `bio`.
- **الأسعار:** مخفية افتراضيًا (`showPrices = false`). فعّلها بعد التأكد من أنها معتمدة وحديثة.

## الصور
الصور في `public/img` بصيغة WebP، ولكل صورة نسخة مصغّرة بعرض 800 بكسل. تُولَّد من صور المؤسسة الأصلية بالأمر:
```bash
python3 scripts/prepare_images.py <مجلد الصور الأصلية>
```
عند استبدال صورة: احفظ الصورة الجديدة بنفس الاسم، وحدّث أبعادها في `src/content/image-sizes.json`.

## التشغيل محليًا
```bash
npm install
npm run dev          # http://localhost:3000
```

## البناء والنشر
```bash
NEXT_PUBLIC_BASE_PATH=/delma npm run build   # الناتج في المجلد out/
```
- **GitHub Pages:** ملف `.github/workflows/deploy.yml` يبني الموقع وينشره على الفرع `gh-pages` مع كل دفع إلى `main`.
  - الإعداد: Settings → Pages → Source: *Deploy from a branch* → `gh-pages` / root.
  - العنوان: `https://sulayksa.github.io/delma/`
- **Cloudflare Pages (اختياري):** اربط المستودع من لوحة Cloudflare بهذه الإعدادات:
  - Build command: `npm run build`
  - Output: `out`
  - المتغيّر: `NEXT_PUBLIC_BASE_PATH` فارغ.
  - يصبح العنوان مثل `delma-aljazeera.pages.dev`.

## نموذج طلب عرض السعر
- **بدون أي إعداد:** يتحقق النموذج من البيانات، ويقبل أرقام الجوال السعودية بصيغها المعتمدة، ويحفظ ما كتبه الزائر. بعدها يفتح واتساب برسالة جاهزة فيها تفاصيل الطلب، ويُطلب من الزائر إرفاق الصور في المحادثة. الموقع لا يدّعي أن الطلب وصل.
- **للإرسال عبر الخادم مع المرفقات:** انشر الموقع على Cloudflare Pages، ثم:
  1. أضف المتغيرات `RESEND_API_KEY` و`QUOTE_TO` و`QUOTE_FROM`. الكود في `functions/api/quote.ts`.
  2. ابنِ الموقع بالمتغيّر `NEXT_PUBLIC_QUOTE_ENDPOINT=/api/quote`.
  3. بعدها لا يُعرض نجاح الإرسال إلا إذا أكد الخادم استلام الطلب.
- **الحماية:** حقل مخفي يصطاد البرامج الآلية، وحد أدنى لزمن تعبئة النموذج، ومهلة دقيقة بين كل إرسالين.

## متغيرات البيئة
انظر `.env.example`. لا يحتوي المستودع على أي مفاتيح أو أسرار.

## الحركة والأداء
- كل الحركات تعتمد على transform وopacity فقط، وتُفعَّل عبر IntersectionObserver وrequestAnimationFrame.
- لا توجد مكتبات حركة ثقيلة.
- الموقع يحترم إعداد `prefers-reduced-motion`.
- البارالاكس الخفيف متوقف على الجوال.
